# DreamRift V5 — Deep Dreams

Gerador dark/minimalista de sonhos estranhos, agora com sonhos maiores e mais complexos.

## O que mudou na V5

- Seletor de tamanho: Curto, Médio, Profundo e Delírio
- Sonhos com estrutura em blocos: abertura, desenvolvimento, evento impossível, descida, símbolo quebrado e final
- Interpretação falsa mais detalhada
- Símbolos com explicações mais longas
- Sonhos mais variados e menos repetitivos
- Ranking, arquivo, favoritos e estatísticas mantidos
- Visual leve da V4 preservado
- Go puro, sem dependências externas

## Como rodar

```bash
cd dreamrift-v5
go run .
```

Abra no navegador:

```txt
http://localhost:8080
```

## Windows

Clique em:

```txt
start_windows.bat
```

Se a porta 8080 estiver ocupada:

```txt
start_windows_8090.bat
```

## Dados

Tudo fica salvo no `localStorage` do navegador.
